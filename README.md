# Game Time Manager

ゲーム依存症対策向けの時間管理アプリです。月曜日から金曜日まで曜日ごとの一日上限を設定し、登録したゲームの使用時間を自動計測できます。過去7日間の使用量をグラフで確認できます。

## 主な機能

- 月曜日から金曜日まで曜日ごとの上限設定
- 登録したゲームプロセスの自動検出・使用時間計測（Windows）
- 現在の使用時間と残り時間の表示
- 上限の80%到達・上限到達時の通知音（上限時は繰り返し、音色・音量の設定と試聴）
- ホーム画面から時間設定・通知音設定へ移動
- 上限到達時の通知（ゲームは自動終了しません）
- 今週（月曜日〜日曜日）の日別使用時間を棒グラフで表示
- SQLite によるローカル保存

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。自動で開かない場合は <http://127.0.0.1:8000/> を開いてください。**ゲームを遊ぶWindows PC上で**アプリを起動すると、3秒ごとに登録したゲームの実行ファイル名を確認して利用時間を記録します。Codespacesなど別のLinux PCでサーバーを動かすと、Windows上のゲームは検出できません。

設定画面で曜日ごとの上限（0〜24時間）とゲームの実行ファイル名（例: `game.exe`）を入力してください。実行ファイル名はWindowsのタスクマネージャーの「詳細」タブで確認できます。上限を超えてもゲームを強制終了する機能はありません。ゲーム名が見つからない場合は、アプリを管理者として起動する必要があることがあります。

ポートを変更する場合は `python main.py --port 8080` のように指定できます。サーバーは既定でこのPC内からのみ接続できます。従来のデスクトップ画面は `python main.py --gui` で起動できます。
